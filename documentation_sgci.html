Plateforme Réclamations
SGCI

Application web interactive construite avec Python Dash pour le suivi des réclamations clients et des indicateurs de performance (KPI) de la Société Générale Côte d'Ivoire.

FrameworkPython Dash + Flask
Base de donnéesSQLite (kpi_historique.db)
Fichier principalreclam_final.py
Version1.0 — Juillet 2026

Les 3 modules

📊

Dashboard Réclamations

Analyse des réclamations clients : KPI, évolutions mensuelles, répartition par agence, groupe de résolution, SLA. Chargement par fichier CSV ou Excel.

📈

Module KPI — Satisfaction & CRC

Import mensuel de 3 fichiers Excel (KPI CRC, KPIS SAT, KPIS SAT PRO). Historisation SQLite, tableaux hiérarchiques UC → Agences, graphiques d'évolution, export stylé.

🌐

Ressource Externe

Lien configurable vers une ressource externe. Pour le modifier : chercher href="https://fr.wikipedia.org/wiki/Lionel_Messi" dans le code et remplacer l'URL.

🏗 Architecture

L'application utilise le pattern display show/hide pour la navigation entre pages — les 3 pages sont toujours dans le DOM, on bascule simplement display: block/none. Ce choix évite les problèmes de routing Dash et de session.

reclam_final.py (fichier unique, ~1820 lignes) │ ├── Pages HTML (variables globales) │ ├── accueil # 3 cartes de navigation │ ├── dashboard # Sidebar filtres + 4 vues │ └── module # Sidebar upload + 3 onglets │ ├── Dashboard Réclamations │ ├── parse_contents() # Lecture CSV/Excel (header ligne 8) │ ├── load_data() # Calcul colonnes dérivées │ ├── generate_view_1..4() # 4 fonctions de graphiques │ └── generate_sla_*() # Tableaux SLA pivot │ ├── Module KPI │ ├── UC_MAPPING # Dict statique UC → [agences] │ ├── AGENCE_TO_UC # Index inverse agence → UC │ ├── init_db() # Création tables SQLite │ ├── _has_numeric() # Filtre lignes vides/en-têtes │ ├── _find_hrow() # Détecte ligne des mois │ ├── parse_crc() # → table kpi_crc │ ├── parse_sat() # → table kpi_sat_v2 │ ├── parse_sat_pro() # → table kpi_sat_pro_v2 │ ├── render_crc() # Affichage onglet CRC │ ├── render_sat() # Affichage onglet SAT │ ├── render_sat_pro() # Affichage onglet SAT PRO │ └── _build_sat_table() # Tableau HTML UC/agences stylé │ └── Callbacks ├── navigate() # Show/hide des 3 pages ├── store_uploaded_data() # Upload réclamations ├── update_all_filters() # Filtres dashboard └── register_kpi_callbacks() # Tous les callbacks KPI

⚙️ Parsers — Fonctionnement

Règle universelle de filtrage des lignes

def _has_numeric(row_series):
    """True si la ligne a au moins une valeur numérique ou %"""
    for v in row_series:
        s = str(v).strip().replace('%', '').replace(',', '.')
        try:
            float(s); return True
        except: pass
    return False  # Ligne vide / en-tête / séparateur → ignorée

Détection de la ligne d'en-tête

def _find_hrow(df):
    """Cherche la ligne contenant des noms de mois"""
    for i in range(min(15, len(df))):
        row_str = ' '.join([str(v).upper() for v in df.iloc[i]])
        if any(k in row_str for k in MOIS_KW):
            return i
    return 0

parse_crc() — étapes

#Action
1Trouve la ligne avec le plus de mots-clés mois dans les 10 premières lignes
2Lit Col B = indicateur, Col C = objectif, Col D+ = valeurs mensuelles
3Ignore les lignes sans numérique (_has_numeric)
4INSERT OR REPLACE dans kpi_crc

parse_sat() et parse_sat_pro() — étapes

#Action
1Boucle sur toutes les feuilles Excel
2Trouve la ligne des mois avec _find_hrow()
3Pour chaque ligne après : ignore si pas de numérique
4Classifie : Col A dans UC_MAPPING → is_uc=1, sinon cherche dans AGENCE_TO_UC
5INSERT OR REPLACE dans kpi_sat_v2 ou kpi_sat_pro_v2

AGENCE_TO_UC = {ag: uc for uc, ags in UC_MAPPING.items() for ag in ags}

Les noms doivent être en MAJUSCULES — le parser convertit automatiquement avec .upper() avant de chercher dans le mapping.

🔧 Scénarios de reprise en main

Cas pratiques pour un développeur ou data analyst qui reprend le projet.

📍 Ajouter une nouvelle agence à une UC
  1. Ouvrir reclam_final.py et chercher UC_MAPPING = { (ligne ~478)
  2. Ajouter le nom de l'agence en majuscules dans la liste de l'UC concernée
  3. Sauvegarder et redéployer (ou redémarrer l'app en local)
  4. Les données déjà en base seront automatiquement reclassifiées au prochain upload
📍 Ajouter une nouvelle UC
  1. Ajouter une entrée dans UC_MAPPING avec le nom de l'UC et sa liste d'agences
  2. AGENCE_TO_UC est recalculé automatiquement — ne pas y toucher
  3. Redémarrer l'application
📍 Ajouter une vue graphique dans le Dashboard
  1. Créer une fonction generate_view_5(data) sur le modèle des 4 existantes (retourne une liste de dbc.Col)
  2. Ajouter l'entrée dans graph_mapping : "btn-5": generate_view_5
  3. Ajouter le bouton dans le layout dashboard (bloc dbc.Row des boutons)
  4. Ajouter les Inputs/Outputs correspondants dans le callback update_all_filters
📍 Modifier le lien de la ressource externe
  1. Chercher dans le code : href="https://fr.wikipedia.org/wiki/Lionel_Messi"
  2. Remplacer l'URL par la nouvelle
  3. Redémarrer l'application
📍 Corriger un mois chargé avec une erreur
  1. Identifier la table concernée : kpi_crc, kpi_sat_v2 ou kpi_sat_pro_v2
  2. Supprimer les lignes du mois en question :
import sqlite3
con = sqlite3.connect("kpi_historique.db")
con.execute("DELETE FROM kpi_sat_v2 WHERE mois='Avril 2026'")
con.commit(); con.close()
  1. Re-uploader le fichier corrigé depuis l'interface en sélectionnant le même mois
📍 Ajouter un nouvel onglet dans le Module KPI
  1. Créer une table SQLite dans init_db()
  2. Créer un parser parse_nouveautruc() sur le modèle de parse_sat()
  3. Créer une zone d'upload dans le layout module avec upload_zone("label", "upload-id", "icon")
  4. Ajouter l'onglet dans dbc.Tabs avec un nouveau tab_id
  5. Créer render_nouveautruc() et l'appeler dans render_tab()
  6. Enregistrer le callback upload dans register_kpi_callbacks()
