Présentation

La Plateforme Ajustage est une application interne SGCI permettant de traiter les opérations de chargeback VISA et Mastercard : import du fichier d'ajustage, vérification et correction des montants, génération des pièces comptables, et clôture avec archivage.

Circuit global :

Fichier VISA/Mastercard (Excel protégé) → Extraction → Vérification/ajustement → Sauvegarde en base → Clôture (génération des pièces comptables + fichier global + TXT) → Téléchargement des livrables.

🖼 Les illustrations ci-dessous sont des maquettes reconstituées à partir du code de l'application (et non de vraies captures d'écran). Elles peuvent être remplacées par de véritables captures dès qu'elles seront disponibles.

Connexion

1

Ouvrir l'application dans le navigateur.

2

Saisir l'identifiant et le mot de passe attribués par l'administrateur.

3

Une fois connecté, le menu latéral affiche les modules disponibles selon le profil de l'utilisateur : VISA et/ou MASTERCARD.

Le bouton 🚪 Déconnexion en bas du menu latéral permet de fermer la session à tout moment.

Extraction d'un fichier

1

Choisir le module (VISA ou MASTERCARD) dans le menu latéral.

2

Importer le fichier Excel d'ajustage reçu (fichier protégé par mot de passe, déchiffré automatiquement par l'application).

3

L'application lit automatiquement la date d'ajustage et la devise depuis la feuille "Ajustage VISA", puis parcourt les feuilles de chargeback (Achat, ATM, Cash Advance — EMIS/RECU) pour en extraire les montants.

4

Cliquer sur "Extraction réalisée" une fois le traitement terminé — un message de confirmation s'affiche.

⚠️ Le module MASTERCARD n'est pas encore disponible dans la version actuelle de l'application.

Vérification / ajustement

Le tableau "Résultat VISA" affiche chaque opération extraite. Certaines colonnes sont modifiables (notamment le montant), les autres sont verrouillées pour éviter les erreurs de saisie.

ColonneModifiable ?
Date d'ajustage, Libellé complémentaire, Type, Module, Numéro de compte, Montant source/destination, Devise, MontantNon
Montant (modifiable)Oui

Trois indicateurs sont affichés en temps réel :

  • Total Original : somme des montants extraits
  • Total Modifié : somme après ajustement manuel
  • Écart : différence entre les deux

Sauvegarder

Le bouton 💾 Sauvegarder enregistre l'extraction (et les ajustements effectués) dans la base de données. Cette étape est obligatoire avant de pouvoir clôturer ou télécharger.

Clôturer

Une fois la sauvegarde effectuée, le bouton ✅ Clôturer devient disponible. Il déclenche :

  • La génération de la pièce comptable Excel
  • La génération du fichier global consolidé
  • La génération du fichier TXT d'intégration comptable
  • L'archivage de l'ensemble dans un dossier horodaté (archives/<date>/<horodatage>)

Un fichier ZIP contenant tous les livrables est ensuite proposé au téléchargement : ✅ Télécharger le dossier de clôture.

Télécharger

Le bouton 📥 Télécharger permet de récupérer individuellement :

  • Le fichier d'extraction (Excel)
  • Les pièces comptables générées
  • Le fichier global consolidé

Historique

L'application conserve un historique de toutes les extractions, des documents générés et des téléchargements effectués, consultable selon les droits du profil utilisateur (filtrage possible).

Questions fréquentes

Le fichier importé ne se déchiffre pas, que faire ?

Vérifier que le fichier correspond bien au format attendu (fichier "Ajustage VISA"). Si le fichier n'est pas protégé par mot de passe, l'application le lit directement sans déchiffrement.

Je ne vois pas le bouton "Clôturer".

Ce bouton n'apparaît qu'après avoir cliqué sur "Sauvegarder" au moins une fois pour l'extraction en cours.

Architecture générale

L'application est un projet Streamlit organisé en modules fonctionnels, avec une persistance SQLite :

projet/
├── extraction/
│   ├── visa.py              # extraction des données VISA (déchiffrement, lecture Excel)
│   └── mastercard.py        # non implémenté ("bientôt")
├── exports/
│   ├── export_piece_extraction.py   # normalisation, regroupement, génération du DataFrame comptable
│   ├── export_piece_comptable.py    # génération de la pièce comptable Excel (mise en forme copiée)
│   ├── export_fichierglobal.py      # génération du fichier global consolidé
│   └── export_fichier_global_txt.py # génération du fichier TXT plat (intégration comptable)
├── base de données (SQLite)  # utilisateurs, historique, documents générés, téléchargements
└── app principale (Streamlit)

Module extraction — extraction/visa.py

FonctionRôle
extraire_visa(uploaded_file)Fonction principale. Déchiffre le fichier (mot de passe SGCI2020+ via msoffcrypto), lit la date d'ajustage et la devise (cellules A3 / F5 de la feuille "Ajustage VISA"), identifie les modules de chargeback actifs (nombre > 0), puis parcourt chaque feuille correspondante pour extraire les montants source/destination.
format_montant(valeur)Convertit un montant brut (centimes) en chaîne formatée avec séparateur de milliers et virgule décimale.
format_account(numero)Formate un numéro de compte (suppression des 3 derniers zéros si présents, découpage en 6+4 chiffres).
construire_libelle(module, account, date_ajustage)Construit le libellé de l'opération selon la nature (CHBK ACHAT / CHBK ATM / CHBK CASH ADV) et la date.
La logique de calcul du montant diffère selon le sens de l'opération : pour les opérations EMIS, le montant source est utilisé directement (devise = 1) ; pour les autres, le montant destination est converti avec le taux de devise lu en F5.

Module export

export_piece_comptable.py

Génère la pièce comptable en partant d'un modèle Excel existant : copie du style de cellule/ligne (copier_style_cellule, copier_style_ligne), recherche de la ligne de total (chercher_ligne_total), ajustement du nombre de lignes du tableau (ajuster_lignes_tableau), nettoyage de la zone de données puis collage cellule par cellule du DataFrame comptable (coller_dataframe_cellule_par_cellule). Fonction d'entrée : generer_piece_comptable(fichier), qui peut produire plusieurs pièces (generer_piece_unique par lot).

export_fichierglobal.py

Fonction generer_fichier_global(fichier_source) : consolide les pièces comptables générées en un fichier global unique.

export_fichier_global_txt.py

Convertit le fichier global (Excel) en fichier TXT plat pour intégration comptable :

  • Recherche automatique du dernier fichier PIECE_COMPTABLE_EMIS_*.xlsx dans data/output (par date de modification)
  • Lecture sans en-tête, colonnes renommées manuellement (16 colonnes : code agence, numéro de compte, sens, montant, libellé — débit et crédit)
  • Une ligne Excel produit une ou deux lignes TXT (une par sens D/C si les colonnes correspondantes sont renseignées)

Format du fichier TXT généré

Chaque ligne est un enregistrement à champs positionnels séparés par |, construit par generer_ligne_txt(...) :

ChampFormat / valeur
Code agence"00" + code (ex: 00123)
Code devisefixe "001"
Numéro de compte9 chiffres, complété par des zéros à gauche
Code opérationfixe "868"
Matriculefixe "4528"
Date clôture / Date ajustageformat JJ/MM/AAAA, date du jour
Montantentier
SensD ou C
Libellé, référenceréférence = "CGB" + date d'ajustage sans "/"
Champs techniques restantsvaleurs fixes/vides (0,00 ; N ; 0 ; etc.) selon un format imposé par le système comptable cible
⚠️ Ce format positionnel est probablement dicté par un système comptable externe (cœur bancaire). Toute modification de l'ordre ou du nombre de champs doit être validée avec l'équipe comptabilité avant mise en production.

Application Streamlit principale

  • st.set_page_config(...) : configuration de la page
  • Authentification puis affichage conditionnel du menu selon le profil (options VISA / MASTERCARD)
  • Sidebar avec habillage SGCI (logo, titre "Plateforme Ajustage") et bouton de déconnexion
  • st.data_editor pour l'édition contrôlée du tableau de résultats (colonnes verrouillées listées explicitement)
  • Calcul en direct des totaux et de l'écart via st.metric
  • Trois actions (sauvegarder / cloturer / telecharger) pilotées par des st.button et l'état de session st.session_state (notamment sauvegarde_ok et extraction_id)
  • À la clôture : génération des pièces + fichier global, archivage disque (shutil.copy2), constitution d'un ZIP en mémoire (BytesIO) proposé au téléchargement

Points de vigilance pour le backup / la maintenance

  • Mot de passe en clair : le mot de passe de déchiffrement (SGCI2020+) est actuellement codé en dur dans extraction/visa.py — à externaliser (variable d'environnement / fichier de config) pour toute évolution.
  • Base SQLite : fichier local — s'assurer qu'il est bien inclus dans la sauvegarde (utilisateurs, historique, documents générés non récupérables autrement).
  • Dossier archives/ : contient l'ensemble des pièces comptables et fichiers globaux clôturés, organisés par date puis horodatage — à sauvegarder avec la base pour garder la cohérence entre historique et fichiers physiques.
  • Dossier data/output : contient les derniers fichiers PIECE_COMPTABLE_EMIS_*.xlsx utilisés par la génération du TXT (recherche par date de modification) — sensible à l'ordre/à la présence des fichiers.
  • Module MASTERCARD : non implémenté à ce jour, à prévoir dans une prochaine itération.
  • Modèle Excel de pièce comptable : la génération dépend d'un fichier modèle dont la mise en forme est copiée cellule par cellule — toute modification de la structure du modèle doit être répercutée dans export_piece_comptable.py.
